# scikit-learn Cookbook

This repository contains code reproductions and theoretical deep-dives for the *scikit-learn Cookbook* (O'Reilly). This is an individual task for the Enrichment for Machine Learning Classes.

## Chapter Summaries
* **Chapter 1: Premodeling Workflow:** Techniques for data preprocessing, scaling, imputation, and feature engineering to prepare datasets for modeling.
* **Chapter 2: Working with Linear Models:** Implementation of linear regression, ridge, lasso, and logistic regression for continuous and categorical predictions.
* **Chapter 3: Building Tree-Based and Ensemble Models:** Training decision trees, random forests, and gradient boosting machines to handle non-linear data and reduce variance.
* **Chapter 4: Support Vector Machines:** Constructing hyperplanes for classification and regression using various kernel tricks.
* **Chapter 5: Post-Modeling Workflow:** Evaluating model performance through cross-validation, hyperparameter tuning, and performance metrics.
* **Chapter 6: Dimensionality Reduction:** Applying PCA and other techniques to reduce feature space while retaining dataset variance.
* **Chapter 7: Unsupervised Learning:** Utilizing K-Means, hierarchical clustering, and other algorithms to find hidden structures in unlabeled data.
* **Chapter 8: Advanced Machine Learning Techniques:** Building complex modeling pipelines and exploring advanced algorithmic implementations.
