# scikit-learn Cookbook

This repository contains code reproductions and theoretical deep-dives for the *scikit-learn Cookbook* (O'Reilly / Packt). This is an individual task for the Enrichment for Machine Learning Classes.

## Chapter Summaries
* **Chapter 1: Common Conventions and API Elements:** Introduction to scikit-learn's design philosophy and estimator APIs.
* **Chapter 2: Pre-Model Workflow and Data Preprocessing:** Techniques for scaling, imputing missing data, and feature engineering.
* **Chapter 3: Dimensionality Reduction Techniques:** Applying PCA and t-SNE to reduce feature space.
* **Chapter 4: Building Models with Distance Metrics:** Implementing K-Nearest Neighbors and distance metrics.
* **Chapter 5: Linear Models and Regularization:** Implementing Ridge, Lasso, and ElasticNet regression.
* **Chapter 6: Advanced Logistic Regression and Extensions:** Multiclass and multilabel classification, alongside advanced logistic regularization.
* **Chapter 7: Support Vector Machines and Kernel Methods:** Constructing hyperplanes and applying the kernel trick for non-linear data.
* **Chapter 8: Tree-Based Algorithms and Ensemble Methods:** Building robust models using Decision Trees, Random Forests, and Gradient Boosting.
